# Учебный проект: Рекомендательная система

## Описание
Рекомендательная система для предсказания лайков пользователей на посты. Проект включает:
- Загрузку данных из PostgreSQL
- Feature Engineering
- Обучение CatBoost модели
- Развертывание сервиса рекомендаций

## Основные шаги

### 1. Загрузка данных
- Данные пользователей (`user_data`)
- Данные постов (`post_text_df`)
- Действия пользователей (`feed_data`)
- Объединение в один датафрейм

### 2. Feature Engineering
- Первая и вторая популярные темы пользователя
- Количество лайков пользователя
- TF-IDF признаки постов (сумма и максимум)
- Объединение всех признаков

### 3. Обучение модели
- CatBoostClassifier с категориальными признаками
- Признаки: демография, темы, TF-IDF, история лайков
- ROC-AUC: 0.663
- Сохранение модели в файл

### 4. Разработка сервиса
- Загрузка признаков в БД
- Функция `get_recommendations()` для генерации рекомендаций
- Возвращает 5 наиболее релевантных постов

## Использование

```python
# Получение рекомендаций для пользователя
recommendations = get_recommendations(user_id=200)
```

## Требования
Python 3.8+

pandas, numpy, scikit-learn, catboost, fastapi, sqlalchemy

Доступ к БД PostgreSQL
